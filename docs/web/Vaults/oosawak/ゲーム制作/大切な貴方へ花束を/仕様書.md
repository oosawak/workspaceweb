# 「大切な貴方へ花束を」Unityオンラインゲーム仕様書 v0.1

## 1. ゲーム概要

| 項目 | 内容 |
| --- | --- |
| タイトル | 大切な貴方へ花束を |
| ジャンル | オンライン・パーティーカードゲーム |
| プレイ人数 | 4~6人 |
| プラットフォーム | スマートフォン |
| 開発環境 | Unity |
| 通信 | オンラインマルチプレイ |
| プレイ形式 | ルーム制 |
| 1ゲーム時間 | 10~30分程度を想定 |
| テーマ | 花・花言葉・プレゼント |
| 主な対象 | 誕生日、記念日、友人同士、パーティー |

原案の中心コンセプトは、花を贈ることで相手に想いを伝えながら、自分の手札をすべてなくすことです。
ただし、悪い意味を持つ花を贈ってしまうと脱落する危険があります。

## 2. ゲームコンセプト
プレイヤーの中から1名を「主役」として選びます。
その他の参加者は、「花贈りプレイヤー」となります。
花贈りプレイヤーは、自分の持っているフラワーカードを主役へ贈ります。
ただし、カードには
- 良い意味の花
- 悪い意味の花
が存在します。
悪い意味の花を主役に贈ってしまうと、主役によってそのプレイヤーをゲームオーバーにできます。
そして、ゲームオーバーになることなく最初に手札を0枚にしたプレイヤーが勝者となります。
ゲーム終了時には、それまでに贈られた良い花をまとめて花束にし、主役へプレゼントします。
この「最後に花束が完成する」ことが、本作の大きな特徴です。元企画でも、花束が完成して主役へ贈られることで特別感を出すことが想定されています。

## 3. プレイヤー役割
### 3-1.プレイヤー
通常プレイヤーは4~6人。
プレイヤーはそれぞれフラワーカードを所持し、順番に「花贈り」を行う。
### 3-2.主役
1ゲームにつき原則1名。
主役は、
- 花を受け取る
- 花言葉を確認する
- 花言葉を公開する
- 悪い花だった場合、贈ったプレイヤーをゲームオーバーにする
- 最後に完成した花束を受け取る
役割を持ちます。
原案では「主役は花言葉辞典を持つ」とされています。    ルールブック1005 (1)
オンライン版では、
主役の画面だけに「花言葉辞典」ボタンを表示
する仕様にします。

- 26種類
- 各2枚

## 8. ゲーム開始処理
ゲーム開始時、サーバー側で、
1. カードを生成
2. シャッフル
3. プレイヤーへカードを配布
4. 花贈り順をランダム決定
します。
これは原案の、
「シャッフルされたフラワーカードが全員に配られる」
「花贈りの順番をランダムに決める」
というルールに対応します。

## 15. GOOD判定
良い意味のカードなら、主役が「ありがとう！」ボタンを押します。
カードは花束エリアに追加されます。

## 16. BAD判定
悪い花だった場合、
画面を暗転。

「OUT」

を表示します。

「このプレイヤーを裁きましょう」

を表示します。

## 17. ゲームオーバー

この企画なら、オンライン化はかなり相性がいいです
特にこのゲームは、リアルカード版よりオンライン版にすると、
「他人の手札を完全に隠せる」
「花言葉辞典を自動化できる」
「サイコロ・カード再配布を自動化できる」
「最後の花束を演出として生成できる」
という利点があります。
私なら最初は3～6人・ルームコード方式・2D UI中心で完成させます。3D空間を先に作る必要はありません。まず「カードを贈る → 花言葉を見る → OUTの緊張感 → 最後に花束が完成する」というコア体験をUnityで動かし、その後に演出を強くするのが良いです。
