# Lyre3 Games

Lyre3 のゲーム、ゲーム実験、開発ツールをまとめたリンク集です。

## Rust wgpu Games

Rust + WebAssembly で作られたゲーム集です。

- [Rust wgpu Games](https://oosawak.github.io/rustgames/play/)
- [Neon Maze 3D](https://oosawak.github.io/rustgames/play/maze3d/)
  - wgpu WebGL を使った一人称視点の3Dネオン迷路。
- [Neon Maze 2D](https://oosawak.github.io/rustgames/play/maze.html)
  - Canvas 2D で描画したネオン迷路。
- [Animal Doku](https://oosawak.github.io/rustgames/play/animal-puzzle/)
  - 短いタップと長押しで動物を見つける配置パズル。
- [Roguelike Dungeon – 3D ダンジョン](https://oosawak.github.io/rustgames/play/roguelike/)
  - 3Dダンジョンを探索するローグライクゲーム。
- [DUNGEON//LOAD](https://oosawak.github.io/rustgames/play/dungeonload/)
  - WASMカートリッジを拾って新しいダンジョンを解放するローグライクのプロトタイプ。

## Pyxel-Rust Examples

Pyxel-Rust、Rust、WebAssembly を使ったゲーム例です。

- [Pyxel-Rust Examples](https://oosawak.github.io/pyxel-rust/examples/)
- [Cubeboy](https://oosawak.github.io/pyxel-rust/examples/cubeboy/)
  - プレイヤー移動、物理、タイル衝突、パーティクル、ボス戦を含むプラットフォームゲーム。
- [Lineboy](https://oosawak.github.io/pyxel-rust/examples/lineboy/)
  - 手続き型レベル生成、動的難易度、敵AI、収集アイテムを含むアクションアドベンチャー。
- [アリサクエスト](https://oosawak.github.io/pyxel-rust/examples/arisa-quest/)
  - AI生成アートとHTML5 Canvasを使ったターン制RPGバトルデモ。
