🎙 Game SE Forge v0.3 Voice SE

「ピコン」「ズドン」「キラン」「シュッ」などの擬音を、声の特徴を使ってゲームSEへ再合成

1. 擬音を録音

短く擬音を言って録音してください。
---長さ
---強さ
---アタック
---明るさ

2. 擬音タイプ

声の長さ・強弱・区切りは自動解析します。さらに簡易自動判定でSEタイプを推測します。違う場合は下の擬音入力やプリセットで上書きできます。
UI・通知
攻撃・衝撃
魔法・SF
動き・コミカル
環境・機械

3. 生成結果

録音後に生成してください。
