# À propos de WorkspaceWeb

WorkspaceWeb est une application de notes dans le navigateur pour les notes Markdown et les ressources de développement de jeux. Les notes et les ressources sont organisées en dossiers et peuvent être consultées ou modifiées dans le navigateur.

## Fonctionnalités principales

- Lire et modifier des notes Markdown ou afficher leur source. Cliquez sur Enregistrer après une modification.
- Ajouter et prévisualiser des images, PDF, fichiers audio, vidéos, pages HTML et ressources 3D. L’aperçu dépend du type de fichier.
- Créer des rapports quotidiens et des comptes rendus depuis le calendrier.
- Modifier des images avec PhotoCraft et des PDF avec PrintCraft.
- Gérer les notes, pièces jointes et dossiers dans la barre latérale.

## Enregistrement dans cette démo

Dans la démo GitHub Pages, les notes modifiées et les fichiers ajoutés sont enregistrés dans le navigateur actuel. Ils ne sont pas synchronisés automatiquement entre navigateurs ou appareils. La version serveur enregistre les fichiers dans un Vault sur le serveur.

## Pour commencer

Sélectionnez une note dans la barre latérale pour la lire. Choisissez Modifier, puis cliquez sur Enregistrer. Le menu de la barre latérale permet d’ajouter des fichiers et des dossiers.
