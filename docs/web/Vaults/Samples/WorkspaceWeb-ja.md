# WorkspaceWeb について

WorkspaceWeb は、Markdown の資料をまとめて扱う Web 版ノートアプリです。
フォルダーで整理したノートやリソースを、ブラウザーから閲覧・編集できます。
[MindZJ](https://zenn.dev/superjohn/articles/752679bdcdc37e)を Web で利用できるように修正しています。

## 主な機能

- Markdown の閲覧、編集、ソース表示。編集内容は保存ボタンで保存します。
- 画像、PDF、音声、動画、HTML、3D データなどの追加とプレビュー。対応形式はファイルの種類によって異なります。
- `.url` ファイルに登録したWebページをアプリ内で表示できます。Ctrl/Cmd を押しながらクリックすると外部ブラウザーで開きます。
- カレンダーから日報や議事録を作成。
- PhotoCraft による画像編集、PrintCraft による PDF 編集が可能です。編集後、保存をすると、Valutsに保存するように修正してます。
- ノート、添付ファイル、フォルダーをサイドバーから管理。

## このデモの保存について

GitHub Pages のデモでは、変更したノートや追加したファイルは現在のブラウザーに保存されます。別のブラウザーや端末とは自動で同期されません。サーバー版では、ファイルはサーバー上の Vault に保存されます。
企業等で使いたい場合、要望があれば、google Groupで認証して利用できるようにする予定です。

## 使い始める

左側の一覧からノートを選ぶと閲覧できます。編集するには「編集」を選び、変更後に「保存」を押してください。ファイルやフォルダーは一覧のメニューから追加できます。
