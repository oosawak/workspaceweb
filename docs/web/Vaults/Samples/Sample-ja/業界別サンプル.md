# 業界別サンプル

WorkspaceWeb をどのような現場で使えるかを紹介する、架空のプロジェクトノートです。社名、人物、数値はすべてサンプル用です。

## サンプル一覧

| 分野 | 使い方の例 |
| --- | --- |
| [ゲーム開発](ゲーム開発/プロジェクト概要.md) | 企画、仕様、議事録、日報、アセット管理 |
| [ソフトウェア開発](ソフトウェア開発/サービス概要.md) | サービス設計、API仕様、課題管理 |
| [映像・デザイン制作](映像・デザイン制作/制作ブリーフ.md) | 制作ブリーフ、素材管理、レビュー記録 |
| [教育・研究](教育・研究/授業計画.md) | 授業計画、研究メモ、参考資料 |
| [製造・建築](製造・建築/案件概要.md) | 案件情報、設計変更、検査記録 |

ノート間のリンク、表、チェックリスト、日報・議事録の書き方を試せます。画像や PDF などのリソース例は、サンプル Vault 内の他のフォルダーにもあります。
