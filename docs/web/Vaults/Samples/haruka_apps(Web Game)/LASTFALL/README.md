## 🎮 すぐに遊ぶ (Play Online)

> 🕹️ **ブラウザですぐにプレイ:**
> **👉 [https://harukaappscreate.github.io/LASTFALL/](https://harukaappscreate.github.io/LASTFALL/)**
> *(PCの Chrome / Edge / Arc、スマートフォン・タブレットのモダンブラウザ向け。モバイルのゲームプレイは横向き)*

### 1. ローカルで遊ぶ
特別なサーバーやインストールは一切不要です。
1. このリポジトリをダウンロード（または `git clone`）
2. `index.html` をお好みのブラウザ（Google Chrome, Edge, Arc などの Chromium 系推奨）でダブルクリックして開くだけ！
3. 画面をクリックすると、BGMおよび立体音響が有効化されます。

### 2. GitHub Pages でオンライン公開する場合
1. リポジトリの **Settings** > **Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` に指定して保存
3. 発行されたURLにアクセスするだけで、世界中どこからでもブラウザでプレイ可能です！

### 言語 / Language

- メニューと設定の言語欄で **Auto / English / 日本語** を選べます。
- Auto はブラウザの優先言語から英語・日本語を順に探します。対応言語がなければ英語を使います。
- 手動選択を端末に保存し、次回から自動判定より優先します。Auto に戻すと保存した指定を解除します。
- メニュー、設定、操作説明、HUD、通知、結果画面、管理者パネルを翻訳します。武器・敵・マップの表示名も切り替わります。
- English is the fallback language. Choose English or Japanese in the menu or Settings; your choice is saved on this device.

### スマートフォン・タブレット / Touch controls

1. メニューは縦向き・横向きの両方で操作できます。ゲーム中は端末を横向きにしてください。
2. 左のスティックで移動し、右側をスワイプして照準を動かします。移動・照準・射撃の同時操作に対応します。
3. **射撃**はタップ・長押しに対応し、射撃ボタンを押したままスワイプして照準も動かせます。**照準**と**ダッシュ**は切り替え式です。リロード、ジャンプ、拾う、武器切替は各ボタンをタップします。
4. **その他**から回復、グレネード、視点切替、ライト、マップ、スコアボードを使えます。訓練場ではボット・モンスター召喚と全消去、管理者モードではパネル・殲滅・テレポートも使えます。
5. 降下中のジャンプボタンは降下・パラシュート展開に使います。スティックを前へ倒すと急降下します。
6. **ポーズ**で一時停止します。縦向きへの回転や別アプリへの切り替えでも停止し、再開ボタンで戻れます。

タッチ端末は自動検出します。設定の **入力方法** で Auto / キーボード・マウス / タッチを選べるので、タッチ対応PCでも切り替えられます。タッチ感度はマウス感度と別に調整できます。

モバイルの初期画質は「低」、ゴア表現は「標準」です。保存済みの設定は優先します。ノッチ・ホームバーを避けてHUDを配置し、小さい画面でもメニューと設定をスクロールできます。端末のGPUによって速度が異なるため、必要に応じて画質を調整してください。

Use landscape for touch play. Move with the left stick, swipe on the right to look, and hold Fire to shoot. Aim and Sprint are toggles. More contains healing, grenades, the map and training actions. The game pauses when you rotate to portrait or leave the app.

## 🌟 主なゲームモード

### 🪂 バトルロワイヤル (PvP / 24人対戦)
- **参加人数:** 24名（プレイヤー 1名 ＋ 自律思考型AI 23体）
- 空輸機からのスカイダイビング＆パラシュート降下からスタート。
- 武器、防具、回復アイテムを現地調達しながら、刻一刻と縮小する電磁ストームから逃れ、最後の1人（Winner Winner）を目指します。
- **高度なAIボット:** アイテムを漁り、遮蔽物を利用し、建物のドア開閉や階段昇降を行いながらプレイヤーと銃撃戦を繰り広げます。

### 🧟 サバイバル (PvE / 感染者の夜)
- 血の月（Blood Moon）が夜空に浮かぶ廃墟で、全10ウェーブにわたる感染者の襲来を耐え抜くPvEモード。
- **敵タイプ:**
  - **グール:** 数で圧倒する標準的な感染者
  - **クローラー:** 地を這い、素早い動きで死角を突く異形
  - **ブルート:** 圧倒的な耐久力と突進力を持つ巨漢
  - **アボミネーション:** 最終ウェーブに君臨する巨大ボス
- ウェーブ間には赤い発煙筒とともに強力な補給物資が投下されます。

### 🎯 射撃訓練場 (Training Ground)
- 全7種類の武器を自由に試射できるサンドボックスエリア。
- 鉄板ターゲット、ポップアップ標的、移動標的、ゴア表現検証用ダミーを設置。
- キー操作で瞬時に敵ボット（`[B]`）やモンスター（`[N]`）を召喚、全消去（`[K]`）が可能。

## ⚡ 注目システム ＆ こだわり機能

- **高度なパルクール・アクション:**
  - 窓枠や低いフェンスに向かってジャンプすると、スムーズに乗り越え（Vaulting）を行います。
  - 高所から飛び降りても、着地時に前転（受身）を行うことで落下ダメージを大幅に軽減。
  - 水場は泳ぎで渡ることが可能（`Shift` で高速スイミング）。
- **過激なゴア ＆ 部位破壊表現:**
  - ヘッドショット時の頭部破裂、散弾や爆発による四肢切断、飛び散る肉片、壁や床に付着する血痕デカール。
  - 演出は設定から「オフ / 標準 / 過激」をいつでも変更可能。
- **視点切り替え & 酔い防止機能:**
  - `V` キーで一人称視点（FPS）と肩越し三人称視点（TPS）をシームレスに切り替え。
  - 画面シェイク・頭の揺れを0にする機能や、FOV（視野角）の調整に対応。
- **完全コード生成アセット (Zero Asset Dependencies):**
  - **音響:** 7種の銃声、弾丸飛翔音、薬莢の落下音、足音、水しぶき、BGMにいたるまで、すべて **Web Audio API によるプロシージャル合成音**。
  - **テクスチャ:** ネオン看板、コンクリート、木目、レンガなどのマテリアルも Canvas 2D で動的生成。
- **管理者チートモード (Sandbox):**
  - メニューでパスワード `admin` を入力すると解放。
  - 神モード（無敵）、弾薬無限、炸裂弾、反動ゼロ、敵位置透視（ウォールハック）、敵AI完全停止、一括殲滅（`[X]`）、照準先へのテレポート（`[T]`）などを自由に発動可能。

## 🛠️ 開発・ビルド環境 (Development)

ソースコードは `src/` 配下に機能別にクリーンにモジュール分割されています。

### 必要要件
- Node.js (v18 以上推奨)

### セットアップ & ビルド
```bash
# 依存関係のインストール (esbuild & Three.js)
npm install

# 変更後の game.js をビルド
npm run build

# 言語判定・翻訳・設定保存・入力の自動テスト
npm test

# 配布用パッケージ (dist/ フォルダ) の作成
npm run build:dist

# ローカルサーバーの起動 (動作確認)
npm run dev
```

依存関係を再現する場合は `npm ci` を使ってください。GitHub Pages を更新する前に `npm test` と `npm run build` を実行し、**ルートの `game.js` と `index.html` を両方コミット**します。`src/` の編集だけでは公開済みゲームに反映されません。

ブラウザでの確認項目：3モードの起動、英日切り替えと再読み込み、タッチでの同時移動・照準・射撃、画面回転と再開、PCのマウス・キーボード操作。iPhone Safari / Android Chrome の実機でも操作感と速度を確認してください。

```text

    ├── hud.js         # ミニマップ・HUD・レティクル描画
    ├── zone.js        # 電磁ストーム収縮処理
    ├── loot.js        # アイテムスポーン・補給物資
    └── actor.js       # アクター基底クラス・アニメーション
```
