## 1. Unityとは？

Unity（ユニティ）は、世界中で使われている最も人気のある**ゲーム開発エンジン**の1つです。
2Dゲーム、3Dゲームだけでなく、VR/ARコンテンツやアニメーション製作など幅広く利用されています。

### Unityの特徴
* **マルチプラットフォーム対応**: Windows, Mac, iOS, Android, Switch, PS5など様々な環境へ出力可能
* **豊富なアセットストア**: 3Dモデルや効果音、便利なツールをダウンロード（または購入）して利用できる
* **C#言語でのプログラミング**: 汎用性が高く強力なC#言語を使ってロジックを実装

## 2. 開発環境の準備

Unityで開発を始めるには、以下の手順でセットアップを行います。

1. **Unity Hubのダウンロード**
   * [Unity公式サイト](https://unity.com/ja) から「Unity Hub」をダウンロードしてインストールします。
2. **Unity Editorのインストール**
   * Unity Hubを開き、「Installs（インストール）」タブから最新の**LTS（Long Term Support: 長期サポート版）**バージョンをインストールします。
   * インストール時に「Visual Studio」などのコードエディタの追加チェックを入れておきます。
3. **新規プロジェクトの作成**
   * Unity Hubの「Projects（プロジェクト）」タブで「New project（新規作成）」をクリックします。
   * テンプレートから「**3D (Core)**」を選択し、プロジェクト名（例: `MyFirstGame`）を決めて作成します。

---

## 3. Unity Editorの基本画面

プロジェクトを開くと、主に5つの主要なウィンドウが表示されます。

| ウィンドウ名 | 役割 |
| :--- | :--- |
| **Hierarchy（ヒエラルキー）** | シーン内にあるすべてのオブジェクト（カメラ、ライト、キャラなど）が一覧表示される場所。 |
| **Scene（シーン）** | 3D空間を自由な視点で操作し、オブジェクトを配置・編集する作業画面。 |
| **Game（ゲーム）** | 実際にプレイヤーから見えたり操作したりする画面（カメラ視点）。 |
| **Inspector（インスペクター）** | 選択したオブジェクトの詳細設定（位置、見た目、スクリプトなど）を表示・編集する場所。 |
| **Project（プロジェクト）** | ゲームで使用する素材（画像、音、3Dモデル、スクリプトなど）を管理するフォルダー。 |

## 4. はじめての3Dオブジェクト作成

まずは画面上に簡単な「床」と「立方体（キューブ）」を作成してみましょう。

### 1. 床（Plane）を作る
1. `Hierarchy` ウィンドウの `+` ボタンをクリック（または空きスペースで右クリック）。
2. `3D Object` > `Plane` を選択します。
3. `Inspector` ウィンドウで `Transform` の `Position` を `(X: 0, Y: 0, Z: 0)` に設定します。

### 2. 立方体（Cube）を作る
1. 再び `Hierarchy` ウィンドウで右クリック。
2. `3D Object` > `Cube` を選択します。
3. `Inspector` で `Position` を `(X: 0, Y: 3, Z: 0)` に設定します（床の上に浮いた状態になります）。

これで、空間上に浮いた立方体と床が完成しました！

## 5. 物理エンジン（Rigidbody）を使ってみよう

Unityには高度な物理計算を行う「物理エンジン」が標準搭載されています。
浮いているCubeに重力を適用して落としてみましょう。

1. `Hierarchy` で `Cube` を選択します。
2. `Inspector` ウィンドウの最下部にある `Add Component` ボタンをクリックします。
3. 検索窓に `Rigidbody` と入力し、表示された `Rigidbody` コンポーネントを選択して追加します。
4. 画面上部中央にある **Play（再生）ボタン** `▶` を押してみましょう！

> **結果**: Cubeが重力に従って落下し、床（Plane）の上に着地して止まります！
> ※再生を停止（もう一度▶をクリック）すると元の状態に戻ります。

## 6. C#スクリプトでオブジェクトを動かす

キーボードの矢印キーでCubeを動かすスクリプト（プログラム）を作成してみましょう。

### 1. スクリプトファイルの作成
1. `Project` ウィンドウの `Assets` フォルダー内で右クリック。
2. `Create` > `Scripting` > `C# Script` を選択します。
3. 名前を **`PlayerController`** に変更します。（※大文字・小文字に注意してください）

### 2. コードの記述
作成した `PlayerController` をダブルクリックしてエディタ（Visual Studioなど）で開き、以下のコードを入力して保存（Ctrl+S / Cmd+S）します。

```csharp
using UnityEngine;

public class PlayerController : MonoBehaviour
{
    // 移動スピード（Inspectorから変更可能）
    public float speed = 5.0f;

    void Update()
    {
        // キーボード（WASD や 矢印キー）からの入力を取得
        float moveHorizontal = Input.GetAxis("Horizontal"); // 左右 (A/D, Left/Right)
        float moveVertical = Input.GetAxis("Vertical");     // 前後 (W/S, Up/Down)

        // 移動方向のベクトルを作成
        Vector3 movement = new Vector3(moveHorizontal, 0.0f, moveVertical);

        // オブジェクトの位置を更新
        transform.Translate(movement * speed * Time.deltaTime);
    }
}
```

### 3. スクリプトをオブジェクトに適用する
1. Unity画面に戻ります。
2. `Project` ウィンドウにある `PlayerController` スクリプトを、`Hierarchy` ウィンドウの `Cube` へ**ドラッグ＆ドロップ**します。
3. `Cube` を選択し、`Inspector` に `PlayerController` が追加されていることを確認します。
4. **Play（再生）ボタン** `▶` を押して、キーボードの矢印キー（または W/A/S/D キー）を押してみましょう！

立方体を自由自在に動かせるようになれば成功です！
