## 1. Unreal Engineとは？

Unreal Engine（UE）は、Epic Gamesが開発した世界最高峰の**リアルタイム3D制作ツール・ゲームエンジン**です。
映画レベルの超リアルなグラフィック表現が得意で、AAAクラスのゲーム開発をはじめ、VTuberのライブ演出、映画・VFX制作、建築・自動車デザインなど幅広い分野で利用されています。

### Unreal Engineの特徴

* **圧倒的なグラフィック性能**: ナナイト（Nanite）やルーメン（Lumen）などの最新技術により、実写レベルの表現が可能
* **ブループリント（Blueprint）システム**: コードを書かずにビジュアルノードをつなぐだけでゲームの処理を作成できる
* **充実したスターターコンテンツ**: 最初から高品質な3Dモデルやエフェクト、操作可能なキャラクターが用意されている

## 2. 開発環境の準備

Unreal Engineで開発を始める手順は以下の通りです。

1. **Epic Games Launcherのインストール**
   * [Unreal Engine公式サイト](https://www.unrealengine.com/) から「Epic Games Launcher」をダウンロードしてインストールします。

2. **Unreal Engineのインストール**
   * Launcherを開き、左メニューの「Unreal Engine」を選択します。
   * 「ライブラリ」タブを開き、Engineバージョンの `+` ボタンを押して最新版（例: `UE 5.x`）をインストールします。

3. **新規プロジェクトの作成**
   * インストール後、「起動」ボタンを押します。
   * プロジェクトブラウザが開くので、**「ゲーム」** > **「サードパーソン（Third Person）」** テンプレートを選択します。
   * プロジェクト設定で「ブループリント」を選択し、プロジェクト名（例: `MyFirstUEProject`）を入力して「作成」をクリックします。

## 3. Unreal Editorの基本画面

プロジェクトが開くと、以下のようなメイン画面が表示されます。

| ウィンドウ名 | 役割 |
| :--- | :--- |
| **ビューポート（Viewport）** | 3D空間を自由に移動し、キャラクターや背景オブジェクトを配置・編集する画面。 |
| **アウトライナ（Outliner）** | シーン（レベル）内にある全アクター（オブジェクト、ライト、カメラなど）がリスト表示される場所。 |
| **詳細（Details）** | 現在選択しているアクターの位置、回転、スケール、素材、物理設定などを変更する場所。 |
| **コンテンツドロワー（Content Drawer）** | ゲーム素材（3Dモデル、テクスチャ、音、ブループリントなど）を管理するフォルダービュー。（画面左下のボタンか `Ctrl + スペース` で開く） |
| **アクティブ化/追加メニュー（＋）** | ライト、図形（CubeやSphere）、カメラなどをシーンに素早く追加するボタン。 |

## 4. レベル（画面）にオブジェクトを配置する

Unreal Engineでは、ゲームの舞台となる空間を**「レベル」**と呼びます。まずは簡単なオブジェクトを置いてみましょう。

### 1. キューブ（Cube）を配置する

1. 画面上部のツールバーにある `＋`（アクターをレベルに追加）アイコンをクリックします。
2. `形状（Shapes）` > `キューブ（Cube）` を選択し、ビューポート上にドラッグ＆ドロップします。
3. ビューポート上でCubeが選択されている状態で、移動ギズモ（矢印）を使って床の上に移動させます。

### 2. トランスフォーム（位置・回転・拡大縮小）の調整

* **Wキー**: 移動モード
* **Eキー**: 回転モード
* **Rキー**: 拡大・縮小モード

右側の **`詳細（Details）`** パネルの「トランスフォーム」セクションから、直接数値を入力して微調整することも可能です。

---

## 5. 物理（Physics）を有効化してみよう

配置したCubeに重力を適用し、空中から落下させてみましょう。

1. ビューポート上で配置した **Cube** を選択します。
2. 右側の **`詳細（Details）`** パネルを開きます。
3. 検索窓に `Physics` と入力するか、「Physics」項目までスクロールします。
4. **`Simulate Physics（物理シミュレート）`** のチェックボックスをオンにします。
5. 画面上部にある **プレイボタン（▶）** を押してみましょう！（ショートカット: `Alt + P`）

> **結果**: ゲームが開始されると、Cubeが重力に従って床に向かって落ち、地面でバウンドして止まります。
> ※ Escキーでプレイを終了します。

## 6. ブループリント（Blueprint）で処理を作る

ブループリント（BP）は、ノード同士を線でつなぐだけでプログラミングができる機能です。
「プレイヤーが触れたらCubeの色が変わる」仕掛けを作ってみましょう。

### 1. ブループリントアクターの作成

1. `Ctrl + スペース` を押して `コンテンツドロワー` を開きます。
2. `Content` フォルダーの空きスペースで右クリックし、`ブループリント クラス（Blueprint Class）` を選択します。
3. 親クラスとして **`Actor`** を選択し、名前を `BP_InteractiveCube` に変更します。
4. 作成した `BP_InteractiveCube` をダブルクリックしてブループリントエディタを開きます。

### 2. コンポーネント（見た目と判定）の追加

1. 左上の `コンポーネント（Components）` パネルで `＋ 追加` ボタンをクリックし、`Static Mesh` を選択して名前を `Cube` にします。
2. `詳細` パネルの `Static Mesh` 項目で「Cube」を選択し、見た目を設定します。
3. 再び `＋ 追加` を押し、`Box Collision`（当たり判定）を追加して、Cubeを囲むくらいの大きさにサイズを調整します。

### 3. イベントグラフでの処理作成

エディタ上部の **`イベントグラフ（Event Graph）`** タブを開きます。

1. 追加した `Box Collision` を選択し、右側の `詳細` パネルの最下部にある `On Component Begin Overlap` の横にある緑色の **`＋`** ボタンを押します。
2. グラフ上に `On Component Begin Overlap (Box)` という赤色のノードが生成されます。
3. そのノードの右矢印（実行ピン）から線を引っ張り、離したところで `Print String` と検索して配置します。
4. `Print String` ノードの `In String` に `「Cubeに触れました！」` と入力します。
5. 左上の **`コンパイル`** ボタンをクリックし、保存してブループリントエディタを閉じます。

### 4. レベルに配置してテスト

1. `コンテンツドロワー` から `BP_InteractiveCube` をビューポート上（キャラクターが歩いて触れる位置）にドラッグ＆ドロップします。
2. プレイボタン（▶）を押してゲームを開始し、キーボードの `W/A/S/D` でキャラクターを動かしてCubeに触れてみましょう。
3. 画面左上に `「Cubeに触れました！」` という文字が表示されれば成功です！

## 7. まとめと次のステップ

これでUnreal Engineの最も基本的なワークフローを体験できました！

* アクターの配置とレベルデザインの基本
* 物理（Physics）エンジンの有効化
* ブループリント（BP）を使ったノードプログラミングとイベント処理

### 次にチャレンジしてみると良いこと

1. **マテリアルエディタの基礎**: 独自のリアルな質感（金属調、ガラス調など）の素材を作ってみる
2. **NaniteとLumenの活用**: 高精細な3Dモデル（Quixel Megascansなど）を無償で導入し、リアルなライティングを試す
3. **UI（UMG）の作成**: 画面上にHPバーやスコアを表示するUIを作ってみる

Unreal Engineはアセット（素材）や機能が非常に充実しているため、アイデア次第で素早くハイクオリティな作品を作ることができます。ぜひ色々な機能を触ってみてください！
