# FilmCraft in MindZJWeb

MindZJWeb bundles the official FilmCraft Web 0.2.1 release from [storytold/filmcraft](https://github.com/storytold/filmcraft/releases/tag/v0.2.1). The files in this directory that belong to FilmCraft are distributed unmodified.

MindZJ's integration lives in the host application. It sends the selected Vault video to the FilmCraft canvas using the browser's file-drop interface. When FilmCraft downloads a project or rendered output, MindZJ saves it beside the source video in the Vault. An export that would overwrite the source is given the `_FilmCraft` suffix.

FilmCraft is dual-licensed under MIT or Apache-2.0. The bundled license texts, required notice, asset attributions, and separate ArtCraft brand terms are available in this directory. ArtCraft brand assets are not open source and remain subject to `LICENSE-brand.txt`.
