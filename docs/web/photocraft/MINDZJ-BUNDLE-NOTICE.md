# MindZJ integration notice

PhotoCraft Web v0.8.2 is based on the official `storytold/photocraft` release. Its upstream source, license files, NOTICE, and asset attributions are included in this directory.

MindZJ adds `mindzj-loader.js` and a script tag in `index.html` to pass a selected Vault image to PhotoCraft and return same-name saves to the original Vault path.
