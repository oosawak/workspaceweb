# WorkspaceWeb 共同編集

Ubuntu Server版の Markdown ノートは、通常のノート画面で編集モードに切り替えると共同編集に接続します。専用のテストページは使いません。

## 動作

- 同じ Ubuntu Server、同じ Vault、同じ Markdown ノートを開いているブラウザー同士で編集内容を同期します。
- 編集操作は Yjs CRDT で統合し、サーバーが Vault 内の Markdown ファイルへ保存します。
- 編集中はツールバーに接続状態、参加者数、保存状態を表示します。
- 接続が切れると編集を読み取り専用にし、未送信の編集が続かないようにします。
- GitHub Pages版、Tauri版、添付ファイルは対象外です。

## 確認方法

1. Ubuntu Server版を起動し、通常の WorkspaceWeb を2つのブラウザーで開きます。
2. 両方で同じ Vault と Markdown ノートを開きます。
3. 一方を編集モードにすると、ツールバーに共同編集の接続状態と参加者数が表示されます。
4. もう一方も編集モードに切り替えます。両方の参加者数が2人になり、片方の入力がもう片方に反映されることを確認します。
5. サーバー上の対象 Markdown ファイルにも変更が保存されたことを確認します。

共同編集を有効にしたノートでは通常の編集ロックを使わず、差分を CRDT で統合します。共同編集以外のファイル保存では既存の編集ロックを使います。

## 制限

- WebSocket が利用できる Ubuntu Server版が必要です。
- ブラウザーが切断中のオフライン編集、リモートカーソル、参加者名一覧は未対応です。
- サーバー外から同じ Markdown ファイルを同時に変更した場合の自動マージは対象外です。
- 複数 Vault を異なるユーザーが同一サーバーで同時に切り替える運用は未対応です。
